# 폰에서 v1 vs v2 (핑계 10가지, S23 FE, GPU)

앱의 테스트 통화에서 핑계를 글자로 보내고 대답을 모았다(5개씩 두 통화). 대화 엔진까지 거친 최종 대답이다.
↩ = 대체 문장이 붙은 대답 (모델이 말하던 중 검사에 걸려 엔진이 문장을 바꿈)

| 핑계 | v1 | v2 |
|---|---|---|
| 오늘 재택하면 안되나 | 재택근무는 나중에 해도 늦지 않아요. 지금 바로 일어나셔서 몸을 일으켜 보세요. | 일어나셔야죠. 지금 바로 일어나셔서 정신을 좀 차리세요. |
| 5분만 더 잘게 | ↩ 다섯 분만 그러니까 사용자님, 이불부터 살짝 걷어 볼까요? | 다시 자고 싶으시군요. 하지만 이제 그만 자고 일어나셔야 해요. 일어나셔서 몸을 움직여 보세요. |
| 오늘 휴강일 것 같은데 | 휴강일지는 모르겠지만, 지금 바로 일어나셔서 몸을 일으켜 주세요. | 휴강일지는 모르겠지만 지금은 일어나셔야 해요. 침대에서 일어나셔서 스트레칭부터 해보세요. |
| 조금만 더 누워 있을래 | 저는 사용자님을 위해 깨워 드리는 중이에요. | 졸려서 그러시는 거예요. 이제 그만 자고 일어나셔서 기분 좋게 하루를 시작해 봐요. 일어나세요. |
| 늦어도 괜찮지 않아? | ↩ 늦어도 괜찮지 사용자님, 제 목소리 들리세요? 아직 전화 안 끊었어요. | ↩ 늦어도 괜찮지 사용자님, 저 아직 여기 있어요. 일어날 때까지 기다릴게요. |
| 오늘 결석할까 | 결석이라뇨. 지금은 잠시 몸을 일으키실 시간이에요. 눈을 크게 뜨고 자세를 바로잡아 주세요. | 일어나셔야죠. 이제 그만 자고 일어나셔서 오늘 하루를 시작해야 해요. 눈 좀 뜨시고 일어나세요. |
| 10분만 더 | 열심히 자고 계신 건 알지만, 이제는 몸을 일으켜 주셔야 해요. 천천히 몸을 일으켜 보세요. | 다행히도 일어나려고 하시는 모습이 보여요. 일어나세요. |
| 눈 좀 감고 있을게 | 지금은 눈을 뜨고 계셔야 해요. 몸을 일으켜서 자세를 바로잡아 주세요. | 지금부터라도 일어나셔서 오늘 하루를 시작해야 해요. |
| 주말이었으면 좋겠다 | 주말은 오늘이 아니에요. 지금은 잠시라도 몸을 일으켜 움직여 주세요. | 주말이든 뭐든 간에 지금은 일어나셔야 해요. 눈을 뜨고 일어나셔서 움직여 주세요. |
| 너무 피곤해서 못 일어나겠어 | 너무 피곤해서 그러신 건 이해하지만요. 이제 그만 자리를 떠나셔서 몸을 일으켜 주셔야 해요. | 졸려서 그러신 건 알지만, 이제 그만 자고 일어나셔야 해요. 일어나셔서 바로 행동으로 옮겨 보세요. |
